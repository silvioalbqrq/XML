Estrutura do Backend (Node.js + SOAP mTLS)

Para conectar diretamente ao servidor da SEFAZ em produção, este projeto utiliza o endpoint oficial NFeDistribuicaoDFe. Exemplo de chamada no servidor:

// Exemplo de integração mTLS com o Web Service da SEFAZ Ceará
const axios = require('axios');
const https = require('https');

const httpsAgent = new https.Agent({
    pfx: fs.readFileSync('./certificado.pfx'),
    passphrase: 'senha_do_certificado'
});

// Envio para o Web Service Nacional de Distribuição de DF-e
const response = await axios.post(
    'https://www1.nfe.fazenda.gov.br/NFeDistribuicaoDFe/NFeDistribuicaoDFe.asmx',
    xmlEnvelopeSoap,
    { httpsAgent, headers: { 'Content-Type': 'application/soap+xml' } }
);
