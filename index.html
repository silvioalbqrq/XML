Esquema procNFe Completo
Ao consultar, o sistema registra a Ciência da Emissão para liberar o XML com produtos e impostos.
Regra do Web Service SEFAZ: Para que a SEFAZ retorne a tag <procNFe> contendo todos os produtos (<det>), NCM, valores e tributos, é obrigatório registrar a autorização/ciência do CNPJ destinatário ou constar na tag autXML.

Fluxo de Código em Node.js (Ciência + Download)

Em ambiente de produção, o processo exige 2 passos SOAP encadeados com o Certificado Digital A1 do CNPJ Destinatário:

// 1. Enviar Evento de Ciência da Emissão (210210) para autorizar
const xmlEventoCiencia = `<envEvento versao="1.00" xmlns="http://www.portalfiscal.inf.br/nfe">
  <idLote>1</idLote>
  <evento versao="1.00">
    <infEvento Id="ID210210${chaveAcesso}01">
      <cOrgao>91</cOrgao>
      <tpAmb>1</tpAmb>
      <CNPJ>${cnpjDestinatario}</CNPJ>
      <chNFe>${chaveAcesso}</chNFe>
      <dhEvento>2026-08-03T09:00:00-03:00</dhEvento>
      <tpEvento>210210</tpEvento>
      <nSeqEvento>1</nSeqEvento>
      <detEvento versao="1.00">
        <descEvento>Ciencia da Emissao</descEvento>
      </detEvento>
    </infEvento>
  </evento>
</envEvento>`;

// 2. Chamar o NFeDistribuicaoDFe para baixar o procNFe Completo com os itens
